## 📱 Flutter Packages

### 🔄 [LifeScope](https://github.com/ebrahimmansur/lifescope)

A Flutter application lifecycle management package that allows individual features to independently observe and respond to application lifecycle events.

**Key capabilities:**
- Independent lifecycle subscriptions per feature.
- Ordered synchronous and asynchronous callbacks.
- Callback error handling and timeout protection.
- Extended iOS background execution time for async operations.
- Desktop application exit guards.
- Automatic lifecycle subscription management for widgets.
- No dependency on a specific state management solution.

[GitHub Repository](https://github.com/ebrahimmansur/lifescope) • [pub.dev](https://pub.dev/packages/lifescope)

### 🖥️ [MorphView](https://github.com/ebrahimmansur/morph_view)

**One UI. Every screen.**

A cross-platform Flutter toolkit for display awareness and adaptive layouts.

It helps applications understand their display environment and adapt to different screen configurations, including window sizes, folds, hinges, display posture, and usable screen regions.

**Key capabilities:**
- Responsive window size classes.
- Foldable and dual-screen display awareness.
- Hinge and fold geometry detection.
- Adaptive two-pane layouts.
- Safe-area and usable-region resolution.
- Immutable display environment snapshots.
- Cross-platform support without requiring native configuration.

[GitHub Repository](https://github.com/ebrahimmansur/morph_view) • [pub.dev](https://pub.dev/packages/morph_view)

### 🔐 DPoP Flutter

A client-side DPoP implementation that helps protect OAuth access tokens from replay attacks through cryptographic proof-of-possession.

- [dpop_flutter](https://pub.dev/packages/dpop_flutter) — Core DPoP implementation.
- [dpop_flutter_dio](https://pub.dev/packages/dpop_flutter_dio) — Dio integration.
- [dpop_flutter_http](https://pub.dev/packages/dpop_flutter_http) — `package:http` integration.
